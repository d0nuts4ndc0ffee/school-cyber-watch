# School Cyber Watch

A public tracker of cyberattacks on US schools, colleges and universities: ransomware, data breaches, unauthorized access and system shutdowns. Major incidents abroad are included too. Every record links to its sources.

The site is updated every morning by an automated research run. Each update is a commit in this repository, so the full history of every record is public.

- `index.html`: the site
- `data/`: the incident records, change log and last-run status
- `UPDATING.md`: the record format and the rules each update follows

How this is researched. Each morning an automated research run checks news outlets, breach trackers and official school notices for new incidents and for updates to existing ones. Figures claimed by attackers are labelled as claims, and new finds are marked unconfirmed until a second source or an official notice backs them up. Incidents under investigation can change, so open the source before relying on a record.

Research is done with Claude. The full record history is public in this site's GitHub repository.
